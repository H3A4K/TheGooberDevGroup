Good vs. Bad Website Design

Good Website - Danforth Bowl

Consistency

  • Size and format of booking box changes from one page to another
  • Booking page should not be on multiple pages
  • Spacing between elements changes from page to page
  • Some images have borders while some do not
  • Variety of fonts and font sizes on pages
  • Images are all different sizes and don't line up

Ease of Navigation

  • Titles are different sizes and colours, distracting
  • No uniformity
  • Three separate party tabs (kids, adult, corporate)

Universal Usability/Responsiveness

  • Transition between phone/tablet is clunky
  • No header or footer

Error Prevention

  • Upon checking console, there are 25 errors signaling issues with font types, titles, and incompatible URLs
  • Gets you stuck on certain pages
  • Request availability form allows you to manually enter date in past

Bad Website - The New York Times

Consistency

  • Sticks to same colour scheme (white + black)
  • Consistent margins and spacing
  • Header stays the same on every page

Ease of Navigation

  • Links are easily accessible at the top of the website

Universal Usability/Responsiveness

  • Hides/shows elements based on available screen size
  • Font sizes change based on screen size
  • Content centers regardless of screen size

Error Prevention

  • Errors are handled properly with proper error messages shown to the user
